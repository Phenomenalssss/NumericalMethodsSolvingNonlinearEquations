## ✨ Возможности

- 🔹 **Три классических метода** уточнения корня: бисекции, хорд и касательных (Ньютона)
- 🔹 **Пошаговый вывод** каждой итерации: `xₙ`, `Δxₙ`, `F(xₙ)` и проверка условия `Δxₙ ≤ ε`
- 🔹 **Сравнительный анализ**: число итераций, время работы (медиана по N запусков) и сравнение с «истинным» корнем
- 🔹 **Истинный корень с точностью 25 знаков** (через `mpmath`), совпавшие цифры подсвечиваются зелёным
- 🔹 **Символьное дифференцирование** — производные `f'(x)` и `f''(x)` вычисляются автоматически через `SymPy`
- 🔹 **Автоматический выбор начального приближения** по условию `f'(x)·f''(x) > 0`
- 🔹 **Красивый интерфейс** в палитре [Catppuccin Mocha](https://github.com/catppuccin/catppuccin) на базе `rich`
- 🔹 **Защита от неверного ввода**: проверка функции, границ отрезка, смены знака, точности

## 🕹️ Использование

После запуска появится главное меню:

```
╭────────── Численные методы ──────────╮
│  Поиск корней нелинейных уравнений   │
│       с заданной точностью           │
│                                      │
│   1  Метод бисекции                  │
│   2  Метод хорд                      │
│   3  Метод касательных               │
│   4  Сравнительный анализ методов    │
│                                      │
│   5  Подсказка                       │
│   6  Выход                           │
╰──────────────────────────────────────╯
```

Далее программа последовательно запрашивает:

| Параметр | Описание | Пример |
|---|---|---|
| `f(x)` | Функция одной переменной `x` | `x^3 - x - 2` |
| `a` | Левая граница отрезка | `1` |
| `b` | Правая граница отрезка (`b > a`) | `2` |
| `ε` | Требуемая точность | `0.001` или `1e-3` |
| повторы | *(только для пункта 4)* число запусков для замера времени | `1000` |

### 📝 Формат ввода функции

| Что | Как писать |
|---|---|
| Переменная | только `x` |
| Степень | `x^2` или `x**2` |
| Умножение | строго через `*`: `2*x` (не `2x`) |
| Функции | `sin(x)`, `cos(x)`, `exp(x)`, `log(x)`, `sqrt(x)` и др. |
| Пример | `x^2 / (x^2 - 1) - ln(x)` |

> ⚠️ На отрезке `[a, b]` функция должна менять знак: `f(a) · f(b) < 0`.

## 📐 Реализованные методы

### Метод бисекции
Отрезок делится пополам, на каждом шаге остаётся половина со сменой знака.

```
xₙ = (left + right) / 2
```

Остановка при `|xₙ − xₙ₋₁| ≤ ε` или при точном попадании `f(xₙ) = 0`.

### Метод хорд
Если `f'(a)·f''(a) > 0`, неподвижен конец `b`, а итерации стартуют из `a`; иначе — наоборот.

```
xₙ₊₁ = xₙ − f(xₙ)·(c − xₙ) / (f(c) − f(xₙ))
```

где `c` — неподвижный конец. Защита от деления на ноль включена.

### Метод касательных (Ньютона)
Начальное приближение — тот конец отрезка, где `f'(x)·f''(x) > 0`.

```
xₙ₊₁ = xₙ − f(xₙ) / f'(xₙ)
```

Если производная обращается в ноль, выводится понятная ошибка.

### Сравнительный анализ
Все три метода запускаются на одних и тех же данных, результат выводится таблицей:

| Название метода | Итераций | Время, мкс | Корень | Истинный корень |
|---|---|---|---|---|
| Метод бисекции | … | … | … | … |
| Метод хорд | … | … | … | … |
| Метод касательных | … | … | … | … |

- **Время** — медиана по заданному числу повторов, с прогревом и отключённым сборщиком мусора (`gc`) на время замера
- **Истинный корень** — бисекция в `mpmath` с 25 значащими цифрами; совпавшая с найденным корнем часть подсвечивается

## ⚠️ Ограничения

- Методы хорд и касательных рассчитаны на случай, когда на `[a, b]` функция **монотонна** и производные **не меняют знак**
- На отрезке должен находиться **один** корень — иначе метод найдёт какой-либо один из них
- Если в ходе итераций возникает деление на ноль, метод сообщает об ошибке, а в сравнительной таблице отображается пометка `ошибка`
