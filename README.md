## ✨ Возможности

- **Три классических метода**: бисекция, хорды, касательные (Ньютона).
- **Любая функция одной переменной** вводится как обычная строка: `x^2 / (x^2 - 1) - ln(x)`. Производные для хорд и касательных строятся автоматически через SymPy.
- **Пошаговый вывод**: для каждой итерации показаны `xₙ`, `Δxₙ`, `F(xₙ)` и вердикт `Δx ≤ ε`.
- **Сравнительный анализ**: время работы, число итераций и найденный корень рядом с эталоном, посчитанным с точностью до 25 знаков. Совпавшие цифры подсвечиваются.
- **Проверка ввода с повторным запросом**: при ошибке программа объясняет причину и просит ввести значение заново, пока оно не станет корректным. Проверяются номер пункта меню, формула функции (только переменная `x`), границы (`a < b`, функция определена и конечна на концах, есть смена знака `f(a)·f(b) < 0`), точность `ε > 0` и число повторов.
- **Оформление в одной палитре** ([Catppuccin Mocha](https://github.com/catppuccin/catppuccin)), которую можно сменить в одном файле.

## 📐 Методы

Во всех методах итерации идут до выполнения условия `|xₙ₊₁ − xₙ| ≤ ε`.

| Метод | Идея | Порядок сходимости |
|---|---|---|
| **Бисекция** | отрезок делится пополам, остаётся половина со сменой знака | линейный |
| **Хорд** | кривая на отрезке заменяется хордой, берётся её пересечение с осью `Ox` | линейный |
| **Касательных** | кривая заменяется касательной, берётся её пересечение с осью `Ox` | квадратичный |

### Формулы

**Бисекция.** Начальное приближение и априорная оценка числа шагов:

$$x_0 = \frac{a+b}{2}, \qquad n > \log_2 \frac{b-a}{\varepsilon}$$

**Хорды.** Условие выбора случая: знак `F′(x)·F″(x)` на `[a; b]`.

| Случай | Начальное приближение | Формула |
|---|---|---|
| `F′·F″ > 0` | $x_0 = a$ | $x_{n+1} = x_n - \dfrac{F(x_n)\,(b - x_n)}{F(b) - F(x_n)}$ |
| `F′·F″ < 0` | $x_0 = b$ | $x_{n+1} = x_n - \dfrac{F(x_n)\,(x_n - a)}{F(x_n) - F(a)}$ |

**Касательные.** Одна формула, но начальная точка зависит от случая:

$$x_{n+1} = x_n - \frac{F(x_n)}{F'(x_n)}, \qquad x_0 = \begin{cases} b, & F'F'' > 0 \\ a, & F'F'' < 0 \end{cases}$$

## 🚀 Быстрый старт

```bash
git clone https://github.com/Phenomenalssss/NumericalMethodsSolvingNonlinearEquations.git
cd NumericalMethodsSolvingNonlinearEquations

pip install -r requirements.txt

python main.py
```

Запускать нужно из корня проекта, рядом с `main.py` и `theme.py`.

**Требования:** Python 3.10 или новее, библиотеки `rich` и `sympy` (вместе с ним ставится `mpmath`).

## ⌨️ Как вводить данные

| Что | Как |
|---|---|
| **Функция** | переменная только `x`; степень `x^2` или `x**2`; умножение только через `*` (`2*x`, а не `2x`); доступны `sin`, `cos`, `exp`, `log`, `ln`, `sqrt` и другие функции SymPy |
| **Границы `a`, `b`** | числа, дробная часть через точку; должно быть `a < b` и `f(a)·f(b) < 0` |
| **Точность `ε`** | положительное число: `0.001` или `1e-3` |
| **Повторы** (сравнение) | целое число ≥ 1; чем больше, тем стабильнее замер времени |

Подсказка по вводу есть в самой программе (пункт меню **5**).

## 🖥️ Пример работы

Тестовая задача: `f(x) = x² / (x² − 1) − ln x` на отрезке `[0.5; 0.6]`, `ε = 0.001`.

| Метод | Итераций | Найденный корень |
|---|---|---|
| Бисекция | 6 | `0.58828125` |
| Хорды | 3 | `0.58857812` |
| Касательные | 2 | `0.58857843` |
| **Истинный корень** | | `0.58857838890955…` |

Одна итерация в консоли выглядит так:

```
╭──────── Итерация 2 ────────╮
│    x2 = 0.588561           │
│   Δx2 = 0.001119           │
│  F(x2) = 0.000077          │
│        Δx2 > ε             │
╰────────────────────────────╯
```

> Время работы зависит от компьютера, поэтому в таблице выше его нет: оно выводится в программе. Число итераций от машины не зависит.

## 📊 Сравнительный анализ

Пункт меню **4** запускает все три метода на одной задаче и строит таблицу. Чтобы сравнение было честным:

- вывод на экран отключён на время замера;
- производные и функции (`lambdify`) готовятся один раз и в замер не входят;
- каждое значение `F` и `F′` считается один раз и переиспользуется;
- перед замером выполняется прогрев, затем берётся **медиана** по всем повторам;
- истинный корень считается бисекцией на числах `mpmath` с точностью до 25 знаков.

## ⚠️ Ограничения

- Условие остановки `|xₙ₊₁ − xₙ| ≤ ε` не гарантирует, что фактическая погрешность не превышает `ε`. Строгая оценка требует границ производной на отрезке.
- Программа не проверяет, что `F′` и `F″` определены и сохраняют знак на всём `[a; b]` (условие применимости хорд и касательных из теории). Подбирать отрезок, на котором оно выполнено, нужно самостоятельно. Если производная не определена в точке, где её считает метод (например, `ln(x)` при `x = 0`), будет выведена ошибка.
- Проверка смены знака смотрит только на концы отрезка, поэтому разрыв функции внутри отрезка она не обнаружит.
- Ограничения на число итераций нет: при слишком малом `ε` (близком к машинной точности `float`, около `1e-16`) метод в редких случаях может не завершиться.
- Корни кратности больше единицы не поддерживаются.
